# CommanderGuard

macOS 菜单栏工具，用于查看本机 RemoteDesktopCommander 服务、只读服务器登记信息，以及本机日志中的调用记录。它不控制 ChatGPT App，也不判断某个对话是否完成或卡住。

`./build.sh` 构建应用，运行 `./build/CommanderGuard.app/Contents/MacOS/CommanderGuard --self-test` 执行离线检查。`./install.sh` 安装应用与本工具自己的登录启动项；`./uninstall.sh` 只移除本工具的应用、快捷方式和启动项，保留源代码及本机状态。

菜单显示 Commander 服务状态和当前本机调用实际执行的动作；文件调用会显示给定路径的末尾目录与文件名，进程命令仅在开头明确包含 `cd 路径 &&` 时显示目录名。完整安全路径保留在悬浮提示和执行日志中，不推测工作目录。确认调用返回后，动作文字继续短暂显示具体操作及实际调用耗时（3 秒后恢复普通状态）。悬浮提示会注明“本机调用已返回”，以便区分进行中和已返回。这只描述单次本机 Commander 调用；被启动的后台进程可能继续运行，且不代表云端任务空闲或完成。日志读取或并发状态不确定时显示“状态未确认”；只有日志证据支持时才显示“当前无工具调用”。“执行日志…”打开原生窗口，按每行一个调用显示最近 100 个本机步骤：时间（本机观察时间）、状态符号、具体动作和耗时。连接与异常及服务诊断默认收起，点击“故障详情…”后显示。普通的收到调用和本机返回事件仍保留在脱敏时间线与 `status.json`，窗口不重复展示这些事件。调用状态每秒最多刷新一次，因此显示耗时按整秒取值，属于本机观察，不代表精确计时。日志中的“App 更新连接已建立／已关闭／准备重连”表示 App 收取会话更新的共享连接状态，不表示 Commander 收到任务或某个对话开始／结束；对话刷新及响应恢复事件只在同一条原始日志行含 `conversationId` 且 SHA-256 命中本机最近核对名录时显示会话名，否则显示“对话名称未识别”。名录名称可能因改名或新增对话而过期，只标记 App 事件，不关联任何 Commander 调用；公共连接事件始终不带会话名。刷新后的 idle 和一段时间没有新事件都不能证明对话成功、空闲或卡住。菜单中的“暂停防休眠（仅影响本机睡眠）”只控制系统防休眠断言，不会暂停日志收集；恢复后会重新阻止本机空闲睡眠。

守护进程只增量读取最多 3 个日期目录、8 个 ChatGPT App 日志和 Commander 日志，每个来源每次最多读 64 KiB；Commander 调用日志每行最多读 4 KiB，App 日志每行最多读 8 KiB。初次遇到的日志从文件末尾开始，只收集此后新增的记录；缺失、不可读、轮换、截断及读取间隔会显示覆盖状态。App 事件必须匹配固定时间戳、`electron-message-handler` 来源与事件名白名单；只保留白名单事件及 `statusAfter` 的 `streaming`、`error`、`idle` 固定值。会话名录从 `~/Library/Application Support/CommanderGuard/conversation-labels.json` 只读载入，最大 64 KiB；其中只存 `verified_at` 和 SHA-256 会话标识到显示名的映射，不存原始会话标识，也不自动刷新。Commander 时间线只保留固定调用类别与安全工具标签。命令正文、结果、URL、令牌、原始会话标识和调用 UUID 不写入时间线。菜单栏文字沿用 40 字截断；执行步骤、悬浮提示和 `status.json` 共用最多 1000 字符的命令预览，保留可识别的程序、参数、引号、管道、链式命令和重定向。例如 `grep -nE 'foo|bar' path | sed -n '1,2p' > out`。已识别的凭据参数、环境变量、请求头、带凭据的网址、JWT 和 UUID 会在对应位置隐藏；未闭合引号、动态命令展开、控制字符或未完整读取的命令显示说明文字。`-c`、`-e` 和 heredoc 内联脚本正文隐藏。预览只用于显示，不执行命令；它不能保证识别任意自定义格式的秘密。

脱敏时间线持续保存在 `~/Library/Application Support/CommanderGuard/timeline.jsonl`，单文件最多 1 MiB，并保留一个轮替副本。`status.json` 是当前状态快照，保留原有执行步骤字段，其中调用耗时只指当前活动调用。工具还会只读查询 Commander 服务登记信息；登记在线仅说明服务器端登记状态，不代表 ChatGPT 对话实时可用。系统在 Commander 服务运行时阻止空闲睡眠。
